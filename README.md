# AI Therapist

### Goal of Project
<p> This repo contains the beginning code for my AI Therapist project. The aim of this project was for me to build on an idea I had attempted many years ago with sentiment analysis and NLP: to decode a user's emotional state and provide them with recommendations to better their well being. While I created a basic pipeline for that, revisiting this project with the boom of generative AI sparked me to rethink my approach. Through completing this first iteration, I was able to learn how to connect to and call an OpenAI model, how to create a Streamlit front end application, and how to use a Python based SQL backend. These are all tools that I've seen being used in the products that I interact with every day so I wanted to give it a try myself. </p> 

### Takeaways

<p>My biggest takeaway from this project is truly how powerful Python can be if the right tools are used. Python is my strongest coding language but I still did not realize how many things you can really accomplish with it. From interacting with LLMs, to maintaining a backend, to designing a UI, Python is a very versatile language that I still have more to learn about. It was also a useful experience to compare how interacting with different models looks like. I've used Amazon Titan Text Express in Bedrock previously and the differences in difficulty of prompting to get the right outputs between the two models was an interesting experience.</p>

### Future Goals

<p>I want to continue to build on the use cases of this application by extracting more specific user inputs that can be stored in the backend for longer term recommendations. Being able to check in on a user on how they are doing now compared to a week, or a month ago would be a valuable feature to have. Similarly, I want to provide visualizations to the user about their progress and give tangible evidence to how their mental health has improved since incorporating the app's recommendations. </p>
